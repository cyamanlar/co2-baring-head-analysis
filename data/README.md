# Data

`co2_bhd_monthly.csv`: monthly mean atmospheric CO₂ dry-air mole fractions (ppm) at Baring Head (BHD), New Zealand.

| Column | Description |
|---|---|
| site | Station code (BHD) |
| year | Year |
| month | Month (1–12) |
| co2_ppm | Monthly CO₂ (ppm) |

**Source:** NOAA Global Monitoring Laboratory (GML), Carbon Cycle Greenhouse Gases group, surface flask network:
https://gml.noaa.gov/aftp/data/trace_gases/co2/flask/surface/txt/co2_bhd_surface-flask_1_ccgg_month.txt

NOAA GML data are freely available. If you use them, follow NOAA's citation guidelines in the file header.
